Android app source code for sale: TZP Tracker

TZP Tracker is a pre-launch Android fitness and personal health-record organization project built with Java and SQLite. Its existing Android Studio source code is offered for acquisition by developers, studios and companies seeking a starting point for their own product development.

Version 2.0.7 source code has been located and successfully built. Basic functional checks were performed on a Samsung Android device and an Android emulator. This is not a Google Play-listed app or a revenue-generating business.

What does the project include?

Workouts and cardio

Workout organization (A–E), exercises, sets, loads and related fitness records.

Body measurements

Personal measurements and historical progress tracking.

Food and daily routines

Meal and protein logs, alongside other personal routine records.

Health-related records

Project modules for medications, applications, reminders, lab exams, reports and local backup.

These are areas developed within the project, not a guarantee that every workflow is production-ready or fully tested.

Technical status and verification

  • Located source: Android Studio project for version 2.0.7, with Java 17 and SQLite.
  • Android configuration: minSdk 26, targetSdk 35 and compileSdk 35 as configured in the located project.
  • Build evidence: a Gradle debug build completed with BUILD SUCCESSFUL, and app-debug.apk was located.
  • Manual device checks: app launch, navigation, saving/editing a fictitious workout record and persistence after device restart were checked on a Samsung device.
  • Emulator checks: installation, navigation and persistence after closing/reopening were checked in an Android emulator.

Important limitations: The above are basic manual checks, not a full quality-assurance, security or regulatory audit. Deletion flows, backup restoration, full module coverage, release signing and store readiness require further assessment. An earlier reference to version 2.0.9 exists, but its source code has not been located or validated. A home-screen version label previously displayed “v2.0.5” while the project configuration specified 2.0.7; a verified rebuilt fix is not yet confirmed.
